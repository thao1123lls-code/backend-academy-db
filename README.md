## Giới thiệu bản thân
Xin chào, mình là Hoàng Phương Thảo, sinh viên chuyên ngành Kỹ thuật Phần mềm tại Đại học Công nghệ Đồng Nai (DNTU). Mình có định hướng theo đuổi các hệ thống phần mềm và đang tập trung trau dồi kỹ năng chuyên môn.

## Mục tiêu học Backend Core
- Xây dựng nền tảng tư duy logic lập trình vững chắc.
- Nắm được bản chất của cách hệ thống hoạt động thay vì chỉ học vẹt các framework.
- Hoàn thành các thử thách thuật toán và biết cách module hóa mã nguồn gọn gàng.
- Tạo tiền đề vững chắc để tiếp tục tiến sâu vào Database và xử lý Service Logic.
